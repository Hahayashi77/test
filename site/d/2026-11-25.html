AIChipBench: Benchmarking LLM Agents for Automated AI Accelerator Design

论文/评测论文速递cs.CL

论文提出 AIChipBench 基准，考察 LLM 编码 agent 能否正确设计 AI 加速器；作者指出解码器在解码步之间携带状态，状态更新出错可能让当前 token 正确、数个 token 后才出错。

DiaCap: Jointly Learning Who Speaks When for Audiovisual Dialogue Captioning

论文/多模态论文速递cs.CV

DiaCap 是音视频 LLM，为视频中每句话输出转写文本、时间戳和说话人视觉描述；因话语时间与音视频说话人分离紧密耦合，模型将两者统一，分两阶段训练。

为什么值得看 做会议或视频内容结构化时，可参考其把时间戳与说话人识别联合建模的做法。

Binfei Ji、Zhiwen Cao、Anqi Yang、Prem Seetharaman
15

CoT-Proxy: Cross-Format Transfer for Distilling Long-Horizon Policies

论文/蒸馏论文速递cs.CL

论文讨论长程策略蒸馏：教师轨迹同时含 chain-of-thought 与动作，标准微调会两者都模仿，但最强教师多为闭源模型，其 chain-of-thought 隐藏在 API 之后，因此提出跨格式迁移的代理方案。

为什么值得看 在看不到教师推理过程时如何蒸馏能力，是当前 agent 训练的现实约束。

为什么值得看 为机器人自主改进补数据覆盖缺口，思路可迁移到其他缺乏失败样本的策略训练。

Draft Calibration for Speculative Decoding: Accelerating LLM Serving by Matching Draft and Target Distributions

论文·推理加速论文速递cs.LG

为什么值得看 speculative decoding 的收益高度依赖 draft 质量，做推理服务的团队值得关注“校准分布”这条路线。

18

Shifter Quantization: Compact Representations for Native Integer Computation

论文·量化论文速递cs.LG

论文提出 Shifter Quantization：通过拼接与移位共享 bit 重构原生位宽的整数操作数，让分组量化的权重能用标准 integer MMA 覆盖完整点积。

为什么值得看 分组量化能提升低比特精度，却会切断整数 MMA 的点积；若该方法成立，可省去额外反量化开销。

Yufeng Huang
