08

jingyaogong/minimind

开源/训练开源趋势

MiniMind 主打约 3 元成本、2 小时从零训练 64M 小模型，主线最小版本约为 GPT-3 体积的 1/2700，并开源 MoE、预训练、SFT、LoRA、RLHF、Agentic RL、蒸馏等全链路代码。

为什么值得看 个人 GPU 即可跑通完整训练管线，适合用来理解流程与各阶段衔接，而非追求模型效果。

09

openvinotoolkit/openvino

开源/推理部署开源趋势

OpenVINO 是开源工具包，用于优化与部署深度学习模型推理，覆盖计算机视觉、语音识别、生成式 AI、NLP，并附带教程、集成与基准测试。

为什么值得看 本地或边缘侧部署推理时，这类推理优化工具是降低延迟的常规选项，可关注它对生成式 AI 的支持程度。

cathrynlavery/diagram-design

工具/Agent开源趋势

一个 agent skill：为 Claude Code、Codex、Cursor 等编码 agent 生成品牌化的编辑级图表，支持 52 种图型，输出自包含 HTML+SVG 单文件，明确不用 Mermaid。

为什么值得看 它示范了 skill 型工具的分发方式：把设计规范固化进单文件产物，减少 agent 生成不可控图表代码的情况。

11

HKUDS/CLI-Anything

工具/Agent开源趋势

项目主张让软件变成 agent 原生：把软件封装成 CLI 供 agent 调用，并配套 CLI-Hub，通过 pip 安装后用 cli-hub install 浏览和安装社区构建的 CLI。

为什么值得看 agent 操作 GUI 一直不顺，CLI 是当下最实用的接口层；这类 hub 若成熟，会直接影响 agent 的可操作范围。

论文/评测论文速递cs.CL

DiaCap: Jointly Learning Who Speaks When for Audiovisual Dialogue Captioning

论文/多模态论文速递cs.CV

DiaCap 是音视频 LLM，为视频每句话输出转写、时间戳与说话人外观描述；因语句时序与音视频说话人分离强耦合，模型将二者统一，分两阶段训练。

为什么值得看 把 diarization 与时间戳放进同一模型，比拼接流水线少一层误差传递，做会议与影视字幕的可以直接关注。

Binfei Ji、Zhiwen Cao、Anqi Yang、Prem Seetharaman

Shifter Quantization: Compact Representations for Native Integer Computation

论文速递cs.LG

Groupwise quantization is used in LLM quantization to improve accuracy at low bit widths, but grouping weights keeps standard integer MMA from spanning the full dot product for efficient GPU inference. We develop a new quantization method, Shifter Quantization (SQ), that reconstructs native-width integer operands by appending and shifting shared bits.

Yufeng Huang
