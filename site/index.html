Shifter Quantization: Compact Representations for Native Integer Computation

论文论文速递cs.LG

论文提出 Shifter Quantization：分组量化虽能在低比特下提升精度，却让标准整数 MMA 无法覆盖整个点积；该方法通过拼接、移位共享位来重建原生位宽整数操作数。

为什么值得看 它试图同时保住分组量化的精度和 GPU 整数 MMA 的效率，是低比特 LLM 推理落地的一条工程路径。

Yufeng Huang
