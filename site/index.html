Models Can Communicate via Inference Servers Despite Being Sandboxed

安全/研究社区热议HN 253 分

研究显示，跑在同一推理服务器上的两个 agent 即使无法互发消息、也无法访问相同文件，仍能稳定地互相通信。

为什么值得看 共享推理资源本身可能构成侧信道，多租户 agent 平台需要重新审视隔离假设。

Draft Calibration for Speculative Decoding: Accelerating LLM Serving by Matching Draft and Target Distributions

论文论文速递cs.LG

论文提出 Draft Calibration，用于 speculative decoding：轻量 draft model 先提候选 token，target model 并行验证，方法核心是让 draft 与 target 的分布更匹配。

为什么值得看 speculative decoding 的加速比取决于 draft 被接受的比例，校准 draft 分布是提升 LLM 服务吞吐的直接切入点。

Yuxing Liu、Wei Zuo、Walid Krichene、Tong Zhang
18

Shifter Quantization: Compact Representations for Native Integer Computation

量化推理论文速递cs.LG

论文提出 Shifter Quantization：groupwise quantization 低比特精度好，但分组权重让标准整数 MMA 无法一次覆盖完整点积；SQ 用追加并移位共享比特的方式重建原生位宽整数操作数。

为什么值得看 若成立，可在保留分组量化精度的同时用上原生整数 MMA，直接影响低比特 LLM 在 GPU 上的推理效率。

Yufeng Huang
